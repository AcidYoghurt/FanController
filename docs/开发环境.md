# Ubuntu 22.04 x86_64 Docker 开发环境

## 固定版本

- 容器系统：Ubuntu 22.04 LTS
- 架构：linux/amd64（x86_64）
- 编译器：GCC/G++ 12
- C++ 标准：C++23
- Qt：6.11.2
- UI：Qt Quick / QML、Qt Quick Controls Basic
- IPC：QtDBus
- 构建：CMake + Ninja
- 打包：`dpkg-deb`

Docker 开发容器不会访问宿主机 `/proc/acpi/call`、EC 或 system D-Bus。硬件集成测试必须在目标笔记本宿主系统进行。

## 自动检测

`docker/common.sh` 会自动检测：

1. `HTTPS_PROXY`、`HTTP_PROXY` 及小写环境变量；
2. GNOME 手动代理配置；
3. `127.0.0.1` 上的常见代理端口；
4. `TZ`、`/etc/localtime`、`/etc/timezone` 或 `timedatectl` 时区。

查看检测结果：

```bash
./docker/build.sh info
```

## 编译

```bash
./scripts/build.sh
```

该命令自动准备官方 Ubuntu 22.04 amd64 基础镜像、构建 Qt 6.11.2 开发镜像，并在容器内执行 Debug 编译。

## 编译并生成 Debian 包

```bash
./scripts/build.sh --pack
```

流程包括：

- Release 编译；
- C++ 单元测试；
- `qmllint`；
- staging GUI 启动测试；
- 非白名单硬件拒绝测试；
- Debian 元数据检查；
- `.deb` 和 SHA256 生成。

输出目录：

```text
dist/
```

## 启动已编译程序

```bash
./scripts/quick_start.sh
```

该脚本不会重新编译；如果 Debug 可执行文件不存在，会提示先运行 `./scripts/build.sh`。

`quick_start.sh` 会在容器内启动私有 D-Bus 和开发专用 mock daemon，无需真实硬件即可检查主要界面流程：

- 自动、全部可控风扇全速和按区域自定义曲线；
- 动态 CPU/GPU 温度和两路 RPM；
- 保存、应用和恢复默认曲线；
- 传感器故障安全保护；
- 后端命令错误 Dialog。

mock 模式必须同时满足 `--mock` 和 `LINUX_THERMAL_ALLOW_MOCK=1`，生产 systemd 服务不会设置该变量，也不会绕过真实硬件白名单。


界面快捷键：

```text
Ctrl+S      仅保存曲线，不改变当前模式
Ctrl+Enter  保存曲线并进入 custom 模式
Ctrl+R      恢复默认曲线
F5          立即刷新 daemon 状态
```

显示策略：

1. 检测到 `DISPLAY` 和 X11 socket 时优先使用 `xcb`；Wayland 桌面会通过 XWayland 显示；
2. 自动生成临时 Xauthority cookie，不使用 `xhost` 放宽访问权限；
3. 检测到 `/dev/dri` 时自动挂载 GPU，并附加设备所属组；
4. 没有 X11/XWayland 时回退到原生 Wayland socket；
5. 容器不连接宿主 system D-Bus，因此后端显示未连接属于预期行为。

## 直接调用 Docker 编译入口

```bash
./docker/build.sh
```

`docker/build.sh` 不接受子命令，只负责准备开发镜像、配置并编译 Debug C++/Qt 项目。

## Docker 文件

Docker 相关代码全部位于：

```text
docker/
├── Dockerfile
├── build.sh
├── common.sh
├── docker_entrypoint.sh
└── requirements.txt
```

## 托盘生命周期测试

GUI 使用 Qt `QSystemTrayIcon`。自动化测试会依次验证关闭窗口后进程仍存在、窗口隐藏、重新显示、再次隐藏，以及托盘退出前通过 D-Bus 恢复自动风扇模式。开发环境可运行：

```bash
LINUX_THERMAL_FORCE_TRAY_FOR_TESTS=1 \
  ./build/docker-debug/src/app/linux-thermal-control --test-tray-lifecycle
```

该测试参数只用于自动化验证，正常启动不需要设置。
